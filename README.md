# TowerStacker2D 🏗️

Juego arcade en 2D desarrollado en **Unity 6** con físicas 2D y asistencia de IA vía **MCP for Unity**.

## 🎮 Jugabilidad
Una grúa oscila de lado a lado en la parte superior. Tu objetivo es soltar cajas y apilarlas sobre una base sin que la torre se desplome.

* **Controles:** `Espacio` / Clic izquierdo / Toque en pantalla para soltar o reiniciar.
* **Mecánica de Perfecto:** Si centras la caja sobre la anterior, obtienes un combo de puntos con efectos visuales y sonoros.
* **Física real:** Cada bloque tiene masa, fricción y respuesta física en tiempo real.
* **Dificultad progresiva:** La grúa acelera gradualmente conforme apilas más bloques.
* **Cielo dinámico:** Transición de día, atardecer, noche y espacio según la altura de tu torre.

## 🛠️ Tecnologías
* **Motor:** Unity 6 (Plantilla 2D URP)
* **Lenguaje:** C#
* **Protocolo:** Model Context Protocol (MCP) para control del Editor
* **Control de versiones:** Git & GitHub
